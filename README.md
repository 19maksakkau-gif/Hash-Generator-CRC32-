🧮 Описание
Hash Generator (CRC32) — это консольная утилита для вычисления хэш-сумм CRC32 и CRC32C для строк и файлов. Программа поддерживает:

✅ Вычисление CRC32 (стандартный полином 0xEDB88320)

✅ Вычисление CRC32C (полином 0x1EDC6F41, используется в iSCSI, SCTP)

✅ Работа со строками и файлами

✅ Пакетная обработка нескольких файлов

✅ Сравнение хэшей (проверка целостности)

✅ Чтение из stdin (конвейер)

✅ Вывод в разных форматах: HEX, DEC, BIN

✅ Прогресс-бар для больших файлов

✅ Кроссплатформенность (Linux, macOS, Windows)

Проект содержит 8 полноценных реализаций на разных языках программирования. Все версии используют оптимизированные табличные алгоритмы для высокой производительности.

🎮 Использование
bash
# Вычисление CRC32 для строки
crc32 "Hello, World!"

# Вычисление CRC32 для файла
crc32 document.txt

# Вычисление CRC32C для строки
crc32 "Hello" --crc32c

# Пакетная обработка нескольких файлов
crc32 file1.txt file2.txt file3.txt

# Чтение из stdin
echo "Hello" | crc32

# Сравнение с ожидаемым хэшем
crc32 document.txt --check 0x12345678

# Вывод в десятичном формате
crc32 "Hello" --dec

# Вывод в бинарном формате
crc32 "Hello" --bin
🛠️ Особенности реализаций
Python – использует binascii.crc32 и встроенный zlib.crc32; поддержка CRC32C через crcmod (опционально).

Go – встроенный hash/crc32 с поддержкой обоих полиномов.

Rust – crc crate для высокопроизводительных вычислений.

C++ – табличный алгоритм с оптимизацией; поддержка CRC32C.

Java – java.util.zip.CRC32 и java.util.zip.CRC32C (Java 9+).

C# – System.IO.Hashing.Crc32 и Crc32C (.NET 6+).

Ruby – Zlib.crc32 и собственная реализация для CRC32C.

Node.js – crc библиотека; поддержка обоих алгоритмов.
